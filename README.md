# pm-porfolio

Personal portfolio of Salima El Khalidi — full stack developer following projects end to end (client needs, feasibility, development, QA, UX), heading toward project management.

Built with Next.js, Tailwind CSS and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

Content (projects, experience, skills) lives in `src/data/content.ts`.
